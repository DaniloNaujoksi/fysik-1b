# ⚛️ Williams Fysiklabb — Fysik 1b fortsättning

Interaktiv plugghjälp på svenska för kursen **Fysik 1b (fortsättning)**.
Byggd för att göra fysikplugget roligt: simuleringar, quiz, XP-system och tveksamma fysikskämt.

## Innehåll

| Modul | Simulering |
|---|---|
| ⚡ Ellära | Ohms lag — krets med lampa och elektroner |
| ☢️ Kärnfysik | Radioaktivt sönderfall med N(t)-kurva |
| 🕰️ Relativitet | Tidsdilatation — raketklocka vs jordklocka |
| 🌍 Energi & Klimat | Energiomvandling Ep ↔ Ek med friktion |
| 🌊 Tryck | Dykare — tryck som funktion av djup |
| 🔥 Värmelära | Koka vatten — E = cmΔT + fasövergång |

## Funktioner

- 📖 Teori med humor — det viktigaste ur kursen, förklarat begripligt
- 🧪 Sex interaktiva canvas-simuleringar
- 🎯 48 quizfrågor med direkta förklaringar
- 🏅 XP-system: från *Fysik-Turist* till *Fysikens Överherre* (sparas i localStorage)
- 🎉 Konfetti vid fullpott (vetenskapligt tveksamt, motivationsmässigt bevisat)

## Teknik

Ren HTML/CSS/JS — inga beroenden, ingen build. Öppna `index.html` eller deploya statiskt.
